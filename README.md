
# GUN MAN — IT'S DARK

A lightweight mobile Battle Royale game prototype.

## Current prototype
- Intro logo screen
- Sky-themed lobby
- Plane and jump sequence
- Parachute and landing concept
- Mobile gameplay controls
- Pause and exit menu

## Development plan
1. Improve the HTML prototype
2. Add real gameplay and collision
3. Build a 3D environment
4. Add weapons and player animations
5. Test on Android devices

## Note
This is an early prototype, not a complete 3D Battle Royale game.
